# 🏙️ AI-Based Smart Civic Issue Reporting System

## 📌 Project Overview

The AI-Based Smart Civic Issue Reporting System is a web application designed to help citizens report civic issues such as potholes, garbage overflow, water leakage, damaged street lights, and drainage problems.

Citizens can submit complaints, upload images, provide location details, and track complaint status. Administrators can manage complaints through an admin dashboard.

## ✨ Features

- Citizen Registration and Login
- Submit Civic Complaints
- Upload Images of Issues
- Add Location Details
- Track Complaint Status
- View Complaint History
- Admin Dashboard
- Complaint Status Management

## 🧰 Technologies Used

- **Programming Language:** Java
- **Backend:** Spring Boot
- **Frontend:** HTML, CSS, Thymeleaf
- **Database:** MySQL
- **Data Access:** Spring Data JPA
- **Build Tool:** Maven

## ⚙️ Setup Instructions

### Prerequisites

- Java 17 or compatible JDK
- MySQL Server
- Maven or the included Maven Wrapper

### Installation Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/varshasawarbandhe5-netizen/AI-Based-Smart-Civic-Issue-Reporting-System.git
   ```

2. Open the project in Eclipse, IntelliJ IDEA, or another Java IDE.

3. Configure your MySQL database and local application settings.

4. Run the Spring Boot application.

5. Open your browser:

   `http://localhost:8080/`

**Security Note:** Do not publish database passwords or API keys. Keep sensitive configuration in local files that are excluded from Git.

## 🎯 Project Objective

To make civic issue reporting easier, improve complaint tracking, and help administrators organize and manage reported issues digitally.
